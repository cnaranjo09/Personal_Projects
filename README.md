# Personal_Projects
Este es un repositorio en el que se encuentran ejercicio y proyectos en diferentes lenguajes, meramente como hobby o pratica


## 🔧 Ejercicios 

### C++

Como correr el codigo en c++, con este primer comando se compila el codigo y se crea el archivo que ejecuta el programa.

``` cpp

g++ archivo.cpp -o nombrePrograma


```

Ahora con este comando se ejecuta el programa
``` cpp


./nombrePrograma

```
los archivos de los ejercicio hechos en c++ se encuentra en la carpeta:
[Archivos c++](https://github.com/cnaranjo09/Personal_Projects/tree/main/cpp)
